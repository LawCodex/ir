# لزوم استفاده از فرم های مخصوص برای ارسال لیست محکومان به اداره سجل کیفری

لزوم استفاده از فرم‌های مخصوص
برای ارسال لیست محکومان به اداره سجل کیفری‌ بخشنامه به کلیه دادسراهای عمومی
وانقلاب ودادگاههای حقوقی دو مستقل سراسرکشور پیرو بخشنامه شماره م 1.63 -

1370.1.6 مقتضی است بعد از این‌، از ارسال لیست‌محکومین قطعی به اداره سجل کیفری
خارج از فرم برگ سجل کیفری خودداری و تربیتی اتّخاذگرددکه کماکان برای اعلام سوابق
محکومین قطعی از فرم‌های برگ سجل کیفری استفاده شود.سرپرستان اجرای احکام و
دادیاران مجری حکم‌، موظفند هنگام اجرای حکم‌، فرم مذکور راتکمیل وامضا نموده و به
اداره سجل کیفری و عفو و بخشودگی ارسال دارند. وصول بخشنامه رابه اداره سجل کیفری
و عفو و بخشودگی اعلام دارید. محمد یزدی رئیس قوه قضاییه
